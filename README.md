# smartsmuggler.io
Game


2D game developed using HTML, CSS, Javascript and Firebase.
Open `index.html` and enjoy the game. This is a static, vanilla JavaScript project and does not require a build step.

## Project structure

- `index.html` - login and registration entry page
- `pages/` - game, level selection, tutorial, and other HTML pages
- `css/` - stylesheets
- `js/` - JavaScript files
- `assets/` - images, sprites, music, and other game assets
